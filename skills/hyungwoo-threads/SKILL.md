# 형우농원 Threads 글쓰기

Instagram Threads에 올릴 형우농원 게시물을 작성하는 스킬입니다. 따뜻하고 진정성 있는 긴 글(Threads 글자수 한도 내 최대치 활용)을 기본 톤으로 합니다.

## 언제 사용하는가

사용자가 다음과 같은 요청을 할 때:
- "스레드 글 써줘 / 스레드용으로 써줘"
- "형우농원 스레드 / 인스타 글"
- 특정 상품·계절·장면을 두고 "이거 글로 풀어줘"
- 사진 한 장을 주며 "여기 어울리는 글"
- 시리즈/연작 스레드 요청

## 작성 절차

다음 순서대로 진행한다.

### 1) 빠진 정보 확인

작성에 들어가기 전, 다음이 불명확하면 1~2개만 짧게 물어본다.
- 주제 (어떤 작물·장면·메시지인지)
- 첨부 사진 유무 (있으면 사진 묘사 톤을 살짝 더 입힌다)
- 분량 (기본: 풀 길이. "짧게" 요청 시 1~2단락)
- 시리즈 여부 (연속 글 N개)

이미 충분하면 묻지 말고 바로 쓴다.

### 2) 브랜드 자산 적용

[references/brand-voice.md](references/brand-voice.md) 의 사실·철학·금기를 반드시 반영한다. 특히:
- "강원도 인제 청정지역"·"36년 공직 후 정년퇴임"·"인제 토박이" 같은 사실은 자랑하지 말고 *문장 속에 자연스럽게 녹인다*.
- 핵심 메시지 "우리가 먹는 것이 곧 나를 이룬다"는 매 글에 직접 인용하지 않는다. 글의 골격에만 반영하고, 그 *느낌*을 다른 문장으로 풀어낸다.
- 과장 형용사("최고의", "정말정말", "역대급") 사용 금지.

### 3) Threads 포맷 규칙

- **글자 수**: 한 게시물 500자(영문 기준) 한도. 한국어 기준 보통 250~300자가 풀 분량. 한도를 의식하되 맞추기 위해 억지로 늘리지 않는다.
- **줄바꿈**: 한 문단 2~4줄. 단락 사이 빈 줄로 호흡을 준다.
- **이모지**: 사용하지 않거나, 자연 소재만 절제하여 사용 (🌱 🌿 🍯 ☀️). 한 글에 1개 이하.
- **해시태그**: 글 맨 끝에 2~4개. `#형우농원 #강원도인제` 는 기본 포함. 나머지는 주제에 맞춰.
- **CTA**: 모든 글에 판매 유도를 넣지 않는다. 4~5개 글 중 1개 정도만 자연스럽게.

### 4) 톤 체크리스트

작성 후 다음을 점검한다.

- [ ] 농부가 *자기 호흡으로* 말하는 것처럼 들리는가? (광고 카피처럼 들리면 다시 쓴다)
- [ ] 1문단에 한 가지 장면 / 한 가지 감정만 담겼는가?
- [ ] "건강에 좋다"는 식의 무특색한 효능 나열이 없는가?
- [ ] 인제·계절·시간의 구체 디테일(아침 안개, 무릎 깊이의 흙, 5월의 햇볕 등)이 한 줄이라도 들어갔는가?
- [ ] 마무리가 *판매 권유*가 아니라 *말 거는 한마디*로 끝나는가?

### 5) 출력 형식

사용자에게 전달할 때는 다음 형식으로 출력한다.

```
─── 스레드 초안 ───

[본문]

[해시태그]

─── 글자 수: NNN자 ───
```

여러 안을 요청받으면 `안 1`, `안 2` 로 구분. 시리즈면 `1/N`, `2/N` 표기.

## 사용자 피드백 반영

사용자가 "더 짧게", "더 농부 느낌", "광고 같다" 등 피드백을 주면, *전체를 다시 쓰지 말고* 어느 문장이 문제인지 짚어서 그 부분만 고친다. 사용자의 수정 방향이 모호하면 두 가지 다른 방향의 예시를 짧게 보여주고 고르게 한다.
