# Threads 글 모음

Claude로 작성한 형우농원 Threads 초안을 이 폴더에 모읍니다.

## 파일명 규칙

`YYYY-MM-DD_주제.md` 형식 권장.

예시:
- `2026-05-16_두릅.md`
- `2026-05-20_명이장아찌.md`
- `2026-06-01_오가피순_시리즈.md`

## 파일 내부 양식 (자유, 참고용)

```markdown
# 두릅 — 2026-05-16

## 안 1
두릅은 손으로 잡을 때 압니다.
...

#형우농원 #두릅 #강원도인제

## 안 2
4월 인제의 새벽은 아직 손이 시립니다.
...

#형우농원 #두릅 #봄나물 #강원도인제

---
- 게시 여부: [ ] 미게시 / [x] 게시
- 게시일: 2026-05-17
- 비고:
```

`upload.bat` 더블클릭이면 새 글들도 함께 GitHub에 올라갑니다.
